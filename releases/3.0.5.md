# Fancy Camera 3.0.5

- 点击拍摄页左下角的照片缩略图，默认打开“全部照片”，清除上次搜索和多选状态。仍可从顶部切换“胶卷”；九宫格中的“我的胶卷”入口保持直接打开胶卷页。
- 每张照片下方增加胶片风格底签：使用该风格的包装底色、条带和底纹，显示完整风格名，支持两行及长名称省略。网格、列表和胶卷内照片都采用同一底签。
- 风格读取每张照片保存的配方，不使用相机当前选项，也不使用胶卷默认风格；照片移卷后保持原风格。缺失或未知风格记录显示中性的“风格未记录”。
- 底纹只用于相册界面，照片及导出内容不加框、不重新显影。底签采用可随系统字号变化的文字，装饰纹理集中在下方，避免遮挡名称；保留照片点击、多选、删除、导出及详情浏览交互。

验证包括实际缩略图路由、77 款风格记录与移卷后的标签来源、缺失和无效记录、胶片底纹栅格绘制及文字留白；继续运行原有相机、照片、归档、主题、GLSL、桌面 EGL 像素和 APK 原签名检查。桌面测试不替代 vivo 真机界面、字体和触控验证。

版本 `3.0.5 / versionCode 62`，保留包名、原签名、照片与设置。发布源码、版本标签与 GitHub Release，附标准 APK、`update.json` 及校验值，不通过 ADB 安装。
