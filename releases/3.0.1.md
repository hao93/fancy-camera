# Fancy Camera 3.0.1

## 主页双滚轮

- 将胶片分类的纵向滚轮、具体风格的横向滚轮恢复到一级拍摄页面，位于焦段滚轮下方。
- 复用原来的滚轮对象与操作：分类上下滑，风格左右滑或点选即时生效；选中项居中，再次点选调整强度，右侧“更多”打开完整胶片库。
- 胶片强度、色温与资料另有设置入口，不再把两个滚轮放在二级抽屉中。

## 第一排与设置

- EV、AUTO / PRO、当前胶卷（默认“手机随拍”）移入顶部工具栏，并在设置中保留独立入口；移除它们原先在取景框内的常驻文字控件。
- 顶部可分别配置闪光灯、定时、画幅、测光、EV、AUTO / PRO、当前胶卷、直方图，共八项；设置按钮始终固定在最右侧。
- 图标多时在第一排横向滑动，保持至少 48dp 点击区域；不挤成小按钮，不另加第二排。原有五项显隐设置继续有效，新增三项默认展示，可恢复默认。
- 显隐只改变入口，不关闭功能。曝光拖动、EV 归零、专业参数及直方图开关逻辑保留；切换显隐不重建相机会话。
- 延续图标随持机旋转、中文保持原布局的规则；开启横屏重排时沿用现有横屏布局。

## 胶片包装风格

- 51 种既有风格各有独立配色与原创胶片标签封面：Gold 金黄、Ektar 酒红黄、HP5 白绿黑、CineStill 深蓝红，以及富士、徕卡、理光、电影和创意类的对应色系。
- 使用色块、装饰条、胶片名称与可用 ISO 信息形成层级，适配圆角、小尺寸及较长名称；封面名称与卡片外的完整名称分别排版。
- 主页滚轮、完整胶片库的卡片底色、胶片资料列表与详情、胶卷封面共用视觉规格。用户选择的封面图片继续优先显示。
- 保留胶片库实时预览开关及其偏好；关闭实时预览时展示包装封面，开启时仍可看当前画面的胶片效果。
- 仅调整界面，固定胶片 ID、调色参数、颗粒、曝光、照片导出与历史底片数据保持兼容。
