# Fancy Camera 3.0.2

- 胶片滚轮的底色与选中框改为共用卡片边界、圆角与变换，选中描边绘制在底色内侧，消除原来框大、底色小造成的空隙。底部色带也裁在同一轮廓内，滑动、点选归中和大字体时保持贴合。
- “更多胶片”固定为细看布局，只保留“细看”标签，移除“总览”标签及其切换入口；搜索、分类、收藏和实时预览开关保留。
- 每张卡片文字上方使用固定宽高相等的预览区域，图片居中裁剪填满正方形，不拉伸、不留适配空边。卡片文字独立排在下方；屏幕窄或字体大时仍可减少列数。
- 裁剪仅用于胶片库展示，不改变取景、拍摄画幅、已保存照片、调色参数或相机输出流程。

1544 项 Java 主机回归、18 项桌面 EGL 像素、9 套 GLSL 与 6 项图标检查通过。新增检查覆盖两种主题、三种字体下选中框与底色的实际绘制边界，以及正方形组件的宽高测量、图片填充参数。主机接口与图形检查不等于 vivo 真机界面验证。

版本 `3.0.2 / versionCode 59`，保留原包名、签名、底片与设置。推送源码和标签，GitHub Release 附标准 APK、`update.json` 与校验值；不通过 ADB 安装。
