# Fancy Camera 2.5.0 · 独立测光与顶部工具定制

版本 2.5.0 / versionCode 55，标准包名 com.silverroom.camera，保留原签名、底片和设置。

## 对焦与独立测光

- 轻点取景画面，同时对焦与点测光，EV 归零；暖金 AF 方框、青绿圆形 AE 拖柄分别表示两个点。紧凑标记持续保留，太阳 EV 提示仍在松手约一秒后隐藏。
- 拖动青绿 AE 标记单独移动测光位置，保留起始触摸偏移，保持 AF 位置与 EV，不重新触发对焦。请求约 16ms 合并；取消保留最后已应用位置，重复相同点位不破坏请求标记。AE 点击只选中，不重新对焦或归零。
- AE 标记以外继续上下拖动调整 EV，不先归零、不移动已有测光点。按持机方向适配竖屏、倒置与两种横屏；多指、取消和拍摄期间防止误触。
- 长按已有 AF／AE 标记锁定当前各自位置；长按空白处建立共同点并锁定，EV 保留。锁定后拖动 AE 先解除组合锁定。保持测光位置意味着亮度继续随该处光线自动调整，只有长按才锁定曝光值。

## 三种测光方式

- 全局自动：清除手动 AE 区域，使用系统默认自动测光。
- 中央区域：可见画面中央 50% 宽、50% 高，不将其描述为厂商原生矩阵或中央加权算法。
- 点测光：最后手动位置，区域边长为可见画面短边的 10%；本次取景尚无点位时从中心开始。

中央和点测光通过原生 AE 区域、权重 1000 实现，实际响应由相机决定。检查当前镜头区域数量及请求键，绑定输出额外要求物理 AE 键；不支持时保留对焦并明确说明，面板禁用不支持的区域选项。参考 [Android AE 区域与变焦后坐标说明](https://developer.android.com/reference/android/hardware/camera2/CaptureRequest#CONTROL_AE_REGIONS)。

模式保存，点位只在本次取景期间有效。同镜头数字变焦重新映射；切换真实镜头、改变画幅、退出取景或进入后台时清除点位和组合锁定，点测光重新从中心开始。预览与拍摄使用统一的点位映射，包含画幅、方向、软件变焦及逻辑变焦后坐标，避免二次套倍率。

请求同时标记锁定代次、测光区域版本和逻辑变焦代次。区域变化废弃旧曝光样本，旧版本／旧锁定结果及返回区域不符时不确认稳定；新区域最多等一秒，超时保持自动曝光并记录未确认。持续测光未变化的连拍不额外等待。区域更新不重建输出会话、不推进逻辑变焦、不清空完整帧缓冲。

## 顶部与设置

默认顺序：闪光灯 → 定时 → 画幅 → 测光方式 → 直方图 → 设置。

- 构图辅助从顶部移到设置，九宫格、黄金分割、对角线、水平仪及中央十字原选择保留。
- 设置新增“顶部工具栏”，分别显示或隐藏前五项，固定顺序，支持恢复默认；隐藏不关闭对应功能，设置中保留各项参数入口。
- 设置齿轮固定右侧 48dp，其余可见入口均匀排列；全部隐藏时仅保留右侧齿轮。修改显隐立即生效，复用原按钮及事件，不重建相机、不重置 EV、焦段或测光点。
- 沿用 22dp 细线、无外框图标，至少 48dp 点击范围。测光以全局、中央框、点状图形区分；只旋转图标。测光面板不压暗取景背景。
- 更新操作提示与无障碍说明。
