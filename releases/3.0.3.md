# Fancy Camera 3.0.3

- 移除拍摄页左下角缩略图下方的数字及对应视图，缩略图继续居中打开“我的胶卷”。内部照片数量记录保留，不清空胶卷张数或拍摄数据。
- 重整胶卷页层级：页头返回、更多按钮改为无厚重底框的图标；“胶卷 / 全部照片”有明确选中态；新建、导入、筛选等按钮缩小可见底框，保留至少 48dp 点击范围。
- 搜索、工具和胶卷摘要作为列表可滚动内容，不再堆叠固定高度控件。摘要根据名称、器材和字体增高，解除原来的 88dp 高度限制，有限张数胶卷显示实际进度。
- 多选的计数和“全选 / 移卷 / 导出 / 删除”固定在底部，并由页面布局预留空间；未选择内容时相关按钮变淡、禁用。
- 胶卷卡片分开显示封面、名称、胶片与状态；照片网格随屏幕宽度、字号调整列数，缩略图保持正方形，文字有独立区域。缺失的照片曝光参数不显示为虚假的零值，测光记录与照片缩略图区分展示。
- 同一列表刷新、退出选择时尽量保留滚动位置。缩略图加载增加目标与可见性校验，搜索结果按数据与关键词缓存，减少无效更新。
- 不改变拍摄、显影、归卷、移卷、导出或七天回收规则；不移动或重写历史原片。

验证覆盖缩略图不再挂载计数视图、后台保存仍保留计数、胶卷工具的可见底框与点击区域、320 / 360 / 432dp 和 100% / 130% / 200% 字体下的按钮间距及网格列数、列表头滚动结构；继续运行既有回归、GLSL、桌面 EGL 像素及原签名检查。主机接口与几何检查不等于 vivo 真机界面验证。

版本 `3.0.3 / versionCode 60`，保留包名、签名、底片及设置，推送源码与标签，GitHub Release 附标准 APK、`update.json` 和校验值；不通过 ADB 安装。
