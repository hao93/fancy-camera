# Fancy Camera 2.4.0 · 拍摄主界面与曝光手势

版本2.4.0 / versionCode 44，原包名、签名、底片与设置保留。

- 去掉取景/暗房/底片底部Tab和整行导航，打开即拍照。图库缩略图与EV位于快门左右，快门保持居中，缩略图进入底片列表。
- 设置移至顶部齿轮。直方图放在取景框右下角，继续支持点击放大；张数在缩略图下方。
- 底片列表继续支持多选导出、接触印样、删除。暗房从列表或单张详情进入二级页，可选底片或从系统相册导入；返回逐级回到列表、拍照，选片取消返回暗房。阻止过期图片加载覆盖新的编辑源。
- 按当前持机方向适配曝光上下手势，支持两种横屏和倒置；方向变化时取消当前手势，点击对焦位置保持准确。
- 点按仅调整AF区域、保留并重发当前EV；不再因暂时读不到曝光能力而清零界面值，镜头就绪后恢复。用户明确重置仍正常归零。
- 保留±3柔和刻度、0.1细调、预览/JPEG一致性及后台显影。

991项Java主机回归、9套GLSL编译/链接、原签名和交付核验通过。包括真实触摸/对焦方法、四方向轴、AF-only策略、恢复曝光、无Tab页面/拍摄区构建、图库和暗房层级返回、多选状态与延后加载；替身不代表vivo实际触控、对焦、AE和字体布局，尚未真机实测。没有通过ADB安装。

参考：[Android持机角度](https://developer.android.com/reference/android/view/OrientationEventListener#onOrientationChanged(int))及[自动曝光区域](https://developer.android.com/reference/android/hardware/camera2/CaptureRequest#CONTROL_AE_REGIONS)。
