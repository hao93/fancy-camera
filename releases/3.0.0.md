# Fancy Camera 3.0.0

拍摄、胶卷档案与随身测光整合为一套胶片摄影工作流。参考 FilmMeter 展示中的模块组织与信息层级，使用原创界面、标签封面和现有 Java / Camera2 / OpenGL 实现。

## 拍摄与界面

- 黑、白、红视觉；保留原主题选择。默认直接进入大取景拍摄页，不恢复底部导航。
- 快门左侧图库进入“胶卷 / 全部照片”，右侧九宫格打开拍摄、胶卷、测光、器材、暗房与设置。
- 胶片收为紧凑入口，展开后保留分组上下滑、胶片左右滑、即时预览、重复点选调强度及完整胶片库。
- EV 移到取景左下角；保留按住上下拖动、轻点重新对焦归零等交互。测光工具中的补偿仅改变实体摄影建议，不改变手机用于测光的零补偿自动曝光。
- 明确的沉浸取景开关；画面轻点始终用于对焦。
- 横屏重排默认关闭。开启后取景居左、控制居右并随屏幕旋转；大字体下控制区可滚动。关闭时沿用中文竖屏、图标随持机旋转。
- 对焦框为白色四角，点测光使用框内红色 AE 圆环，可拖出独立测光；非点测光不提供 AE 拖动，点击对焦不自动切换测光方式。
- 追加半格、6:7、6:17、XPAN 65:24 画幅；旧画幅编号保持，预览与 JPEG 共用裁切定义，RAW 不套画幅裁切。

## 手机 AUTO / PRO

- 按当前真实镜头、逻辑相机与可写请求键核对手动 ISO、快门、原生白平衡和光圈能力；未开放的项目明确禁用。
- PRO 的 ISO 与快门共同进入原生手动曝光；固定光圈只读，只有实际公开可写的多档光圈才可调整。
- 全手动暂停自动 EV 补偿和手机闪光灯，ΔEV 仅以上次同镜头 AUTO 读数作参考，明确标注其不是实时测光。返回 AUTO 恢复之前自动拍摄的白平衡等状态及 EV、闪光灯。
- 预览与快门使用独立参数代次；拍摄期间的变更延后生效。JPEG 实际 ISO / 快门与冻结的手动请求不符时，本次不保存并恢复 AUTO，不自动补拍。

## 胶卷、胶片与器材

- 新建、编辑、置顶、排序、切换胶卷，记录胶片、器材、日期、容量、迫冲和工艺；菜单可设置拍摄中、已拍完、冲洗中、已完成，设为已完成可作归档。
- 默认不限张数“手机随拍”；旧底片以可重复执行的迁移归入“历史底片”。迁移只增加 SQLite 关联，不移动或重新显影旧文件。
- 按快门时冻结胶卷、胶片与参数；后台显影完成归入原卷。同卷可以逐张换风格，副本不重复计入曝光张数，满卷提醒不锁快门。
- 胶卷详情有标签封面、进度、照片网格 / 参数列表、搜索、筛选、多选、移卷、补填与整卷导出。支持自定义封面；删除胶卷保留照片和记录，照片继续使用七天回收。
- 手机照片、相册导入和纯测光记录分开保存；原始参数、用户补填与实体摄影建议独立记录。测光记录也有七天回收入口。
- 系统照片选择器支持多张导入，原件按字节保留并计算校验值，预览 JPEG 单独生成；不以导入时间替代缺失拍摄日期。
- 胶片资料按彩色、黑白、反转片分类，可编辑档案 ISO、关联风格、日光 / 钨丝灯倾向及封面。内置配方是数字风格模拟，资料 ISO 是可编辑的工作值，不设置手机传感器 ISO。
- 相机、镜头、闪光灯、滤镜档案与通用模板，保存画幅、焦距、光圈、GN、ND 等资料。器材信息不会伪装成手机成片 EXIF。

## 随身测光与工具

- 根据经过当前请求核验的实际 ISO、快门和光圈计算 EV100；胶片滤镜不参与测光。进入测光临时使用手机 AUTO、零补偿及关闭闪光灯，退出后恢复手机拍摄设置。
- 全局、中央、点测光；指定实体胶卷标称 ISO / EI 和光圈或快门，计算另一项；冻结读数与按镜头、固件保存的校准偏移。
- EI / 迫冲只计算一次；先应用 ND，再使用有来源的 ILFORD 倒易率预设修正长曝光。未知胶片不猜系数。
- 手动距离、景深、超焦距、基于 ISO100 / 米 GN 的手动直闪功率建议；只有已标定且有效的相机元数据才提供对焦距离估计，不称为激光测距。
- 器材等效视角参考、彩色 / 黑白物理滤镜的屏幕模拟、亮度分布的高低调建议。建议不自动调整曝光，屏幕模拟不宣称准确复现实体胶片光谱。
- 默认只测不存；快门位置明确显示“记录”，主动记录后才归入所选实体胶卷，可附取景参考图。每个异步参考图绑定自己的记录，后续记录不能抢占旧图。
- 前台长曝光计时，按截止时刻恢复剩余时间；不承诺后台准点提醒。
- 位置默认关闭，用户开启并授权后，仅前台获取有效位置；没有有效位置则省略。新拍摄可记录到档案与 JPEG GPS。

## 导出与兼容

- 原件字节导出、逐张排版、三列三行接触印样与整卷导出，增加黑边与相机、镜头、曝光参数开关。单张最长边 4096，接触印样 2896×4096，最多九张一页，超出自动分页。
- 五类信息可独立关闭，完整保留横竖比例；缺失原始信息不猜测，补填值单独标识，不写成原始 EXIF。CSV 使用 UTF-8，实际参数、补填与实体建议分列。
- 保留原包名 `com.silverroom.camera`、签名、底片、固定风格 ID、配方、主题、更新偏好、真实光学路线、快速切镜和完整帧缓冲。
- 发布 `3.0.0 / versionCode 57`，附标准 APK、`update.json` 和 `SHA256SUMS.txt`；不通过 ADB 安装。

## 验证范围

1484 项 Java 主机检查、18 项桌面 EGL 像素、9 套 GLSL 和 6 项图标栅格检查通过，APK 原签名与对齐另行核验。执行既有回归和新增测光数学、手动原生请求、数据来源、不可变归卷、布局状态、字节 IO、黑白排版及实际主机 SQLite 测试；继续检查九套 GLSL、十八项桌面 EGL 像素、APK 对齐与原签名。

主机 SQLite 与 Android 接口适配测试不等于 vivo 真机测试。尚未实机确认本固件各镜头的手动参数响应、测光精度、JPEG 一致性、传感器、横屏界面和手势体验；不承诺达到原生相机的效果或无黑屏。
