# Fancy Camera 2.3.3 · 切镜过渡与焦段提示稳定性

版本2.3.3 / versionCode 38，保留标准包名、原签名、底片及设置。

## 镜头切换

- 旧镜头返回实际关闭回调后立即在相机线程排队尝试下一镜头，移除此前额外的180ms固定延时。仍保留CameraHandoff关闭屏障：旧设备未关闭、多个设备仍在退出或应用进入后台时不能提前打开。
- 依据[Android CameraDevice.StateCallback 文档](https://developer.android.com/reference/android/hardware/camera2/CameraDevice.StateCallback#onClosed(android.hardware.camera2.CameraDevice))使用实际onClosed通知；没有以计时器代替设备关闭，也未更改光学路由、相机输出尺寸或首帧验证。
- 切镜期间在上一张完整取景上叠加暖金／青绿机械光圈环、短刻度和目标毫米数。新镜头真实就绪后160ms淡出；失败、后台及离开取景立即清除，不拦截对焦和曝光手势，不写入照片。
- 过渡绘制限约30fps，不进行额外相机截图或重建；系统关闭动画时显示静态提示。真实硬件打开、配置及首帧仍取决于系统与固件，未承诺所有镜头瞬间切换。

## 焦段提示

- 滑动时固定使用可容纳小数焦段的展开布局，毫米提示保持12sp，位置不随数字位数变化；解除对动态边框的裁切，避免文字边缘闪动。
- 手指松开、惯性或吸附结束后，提示和选中框保留900ms；随后200ms只淡出文字，完成后再收回框。短暂停顿和连续重滑取消旧的隐藏回调，不反复缩放。
- 取消、多指、拍摄禁用、页面离开立即清理延迟与动画；初始仍使用贴近数字的紧凑框。提示动画不影响拍摄是否就绪的判断。
