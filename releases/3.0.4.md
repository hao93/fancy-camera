# Fancy Camera 3.0.4

胶片库新增 26 款原创色彩配方，共 77 款；均可用于实时取景、拍摄、暗房、收藏与配方保存。

- **哈苏灵感，6 款**：自然、柔和人像、风光、暖阳、冷调、细腻黑白。新增独立“哈苏”分组，放在富士、徕卡、理光之后，突出自然色彩、柔和高光及克制颗粒。
- **经典胶片，6 款**：Kodak Portra 400、Portra 800、UltraMax 400、ColorPlus 200、Fujifilm Superia 400、Kodak Ektachrome E100。并入“经典胶片”，保留原有 Gold、Ektar、Kodachrome、800T、HP5 与宝丽来。
- **电影灵感，14 款**：沙丘·沙金、银翼杀手2049·霓虹、银翼杀手2049·荒漠、爱乐之城·蓝调、布达佩斯·粉彩、黑客帝国·代码绿、星际穿越·冷空、奥本海默·黑白、她·柔暖、天使爱美丽·红绿、花样年华·暖影、重庆森林·夜色、可怜的东西·奇彩、小丑·冷城。并入“电影美学”，连同原有风格共 19 款。
- 新风格采用独立的原创胶片包装配色、短名称和中英文搜索；保持“细看”方形预览、滚轮即时切换与强度调节。
- 新增风格默认使用轻颗粒，哈苏系列尤其细腻；色调、反差和高光过渡仍是主要效果。
- 旧风格 ID、收藏分组 ID 和全部历史配方保持不变。新配方仅追加到 ID 51–76，不改写旧底片或已有照片。
- 电影名称中的年份不会冒充标称感光度；无标称 ISO 的哈苏或电影配方不提供“用于实体测光感光度”，可在自定义资料中单独填写。

## 参考与说明

哈苏系列根据[哈苏官方 HNCS 介绍](https://www.hasselblad.com/learn/hasselblad-natural-colour-solution/)中自然色彩、柔和过渡的设计方向制作。这里的六个场景化配方是 Fancy Camera 的原创延伸，并非哈苏官方模式、HNCS 或中画幅画质复制。

电影配方是从作品视觉中提取的局部色彩灵感，并非整部电影的统一调色或官方 LUT。原作效果也依赖灯光、美术、镜头与曝光。参考[ARRI《银翼杀手2049》灯光访谈](https://www.arri.com/news-en/lighting-blade-runner-2049-)、[Kodak《爱乐之城》摄影访谈](https://www.kodak.com/en/motion/blog-post/linus-sandgren/)、[Kodak《可怜的东西》摄影资料](https://www.kodak.com/en/motion/blog-post/poor-things/)以及[胶片厂商资料](https://www.kodakprofessional.com/sites/default/files/wysiwyg/film/KODAKPROFESSIONAL_Film_Brochure2018.pdf)。选择以常见摄影与电影配色方向为准，不宣称覆盖所有风格或提供实时热度榜。
