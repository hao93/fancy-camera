# Fancy Camera 2.3.7 · 取景与成片曝光同步

版本2.3.7 / versionCode 42，保留标准包名、原签名、底片和设置。

- 修复预览曝光已变化，拍照会话重新测光却未继承该曝光的链路缺口。冻结本张EV；尚未生效的非零EV最多等待1秒，稳定后立即拍摄，0EV不增加固定等待。
- 分时拍照在设备公开支持时继承对应镜头的实际快门、ISO及可用后级数字增益；并发会话保留已稳定AE。检查逻辑/物理相机能力、参数范围与请求键，闪光模式保留自动测光。
- 对成片实际曝光结果进行核对，只补足已确认的差值，避免已生效EV重复叠加。JPEG补偿进入实际显影像素，胶片强度0%、50%、100%均有效；真实DNG不套用软件亮度调整。
- 设置EV、实际返回EV和成片补偿分别记录。未知EV标记为未返回，不以请求值冒充真实结果或写入虚构EXIF；重显影保留可用的曝光信息。
- 后台显影、四张待处理队列、缩略图刷新、光学镜头边界和拍摄保留帧继续保留。

928项Java主机回归与9套GLSL编译/链接检查通过；新增49项曝光专项检查包含生产请求方法、正负EV与光圈差异、主摄/超广角/长焦物理输出、能力缺失、稳定等待及超时、缺失元数据、重复补偿和Film.develop真实像素路径。连续拍摄回归覆盖先后两张不同EV互不污染。主机替身不能确认vivo固件实际输出、JPEG/RAW、闪光和厂商色调映射，未进行手机安装或真机验证。

参考：[Android曝光补偿与AE锁定说明](https://developer.android.com/reference/android/hardware/camera2/CaptureRequest#CONTROL_AE_LOCK)及[后级数字增益](https://developer.android.com/reference/android/hardware/camera2/CaptureRequest#CONTROL_POST_RAW_SENSITIVITY_BOOST)。
